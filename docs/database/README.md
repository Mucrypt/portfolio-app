## 💡 Key Features

✅ **Auto-generated TypeScript types** from your Supabase database  
✅ **Full autocomplete** for all tables and columns  
✅ **Version control** your schema through Git  
✅ **Local development** without touching production

## 🚀 Quick Commands

```bash
npm run db:types      # Generate TypeScript types
npm run db:pull       # Pull schema from Supabase
npm run db:local      # Start local Supabase
```
